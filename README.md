## Comece por aqui

### [prompts-e-skills](https://github.com/AndreCia/prompts-e-skills)

Biblioteca gratuita de prompts, skills e ferramentas de IA em português.
Organizada por finalidade, com material novo toda semana.

| | |
|---|---|
| Imagens | Prompts para gerar imagem com acabamento profissional |
| Copy e vendas | Headlines, anúncios, e-mails, páginas de venda |
| Texto e conteúdo | Roteiros, legendas, artigos |
| Produtividade | Resumos, organização, apoio a estudo |
| Negócios | Análise, estratégia, pesquisa de mercado |

Você não precisa saber programar para usar. É copiar e colar.
